# Scope and Requirements

## Tên đề tài
Hệ thống Quản lý Ký túc xá trường Đại học Kanto.

## Loại hệ thống
Website Client-Server.

## Công nghệ
- PHP
- MySQL
- PDO
- HTML/CSS/Bootstrap
- JavaScript
- WAMP
- Git/GitHub

## Tác nhân
- Khách vãng lai
- Sinh viên
- Nhân viên quản lý KTX
- Nhân viên kế toán
- Quản lý KTX
- Timer

## Phạm vi chức năng
- Đăng nhập và phân quyền
- Đăng ký lưu trú
- Xét duyệt đơn
- Quản lý sinh viên
- Quản lý hợp đồng
- Điện nước
- Hóa đơn
- Phản ánh sự cố
- Xử lý phản ánh sự cố
- Thông báo
- Xem báo cáo và thống kê
- Chatbot AI
- Xem thông tin phòng
- Xem hướng dẫn

## Phạm vi AI

AI chỉ:
- hỏi đáp thông tin chung về KTX;
- hướng dẫn sử dụng hệ thống.

AI không:
- truy cập dữ liệu cá nhân;
- tra cứu hóa đơn cá nhân;
- tra cứu hợp đồng cá nhân;
- phân tích phản ánh sự cố.
