# Sequence Diagrams

Thư mục này chứa các Sequence Diagram của Hệ thống Quản lý Ký túc xá Kanto.

Các sơ đồ hiện được lưu dưới dạng PNG.

Khi triển khai một Use Case:

1. Đọc đặc tả Use Case trong `docs/02-use-cases/`.
2. Xem Sequence Diagram tương ứng trong thư mục này.
3. Đối chiếu với Wireframe trong `docs/05-ui/`.
4. Đối chiếu với CSDL hiện tại.
5. Không tự thay đổi nghiệp vụ nếu phát hiện khác biệt giữa các tài liệu.
